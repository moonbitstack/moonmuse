02 · Four bodies

Edit one, and the rest follow

Every pane is a text field. Change a value, add a message, or press ↻ to make that pane the source: the other three are read and written by the four dialects, not by this page.

The model travels with the request: convert a body and the same model name appears where the target format keeps it — for Gemini, in the URL.

03 · House rules

What breaks a second integration

Four things, in the order they usually bite. None of them is a bug in either side; each is what the specification decides.

  • Anthropic requires max_tokens. Omit it and the request is rejected; there is no default. OpenAI and Ollama fill one in.
  • Gemini puts the model in the path and the knobs under generationConfig. Temperature, output cap and stop sequences are renamed and relocated at the same time.
  • Ollama nests generation options under options, and streams by default. Ask for one response with "stream": false.
  • OpenAI has no top-level system field. The system prompt is the first message, so order carries meaning.

04 · Streams

Four shapes of the same event

The deltas are one type. What arrives on the socket is not: a JSON chunk, seven named events, a candidate array, or one object per line.

OpenAI · server-sent events
data: {"choices":[{"delta":{"content":"Be"}}]}

data: {"choices":[{"delta":{"content":"cause"}}]}

data: [DONE]

One unnamed event per chunk; the stream closes with a sentinel.

Anthropic · named events
event: message_start
data: {"type":"message_start",...}

event: content_block_delta
data: {"type":"content_block_delta","index":0,
       "delta":{"type":"text_delta","text":"Be"}}

Seven event names, and a block index that has to be tracked.

Gemini · candidate array
data: {"candidates":[{"content":{"parts":
       [{"text":"Be"}],"role":"model"}}]}

The same SSE frame, with the text nested three levels down.

Ollama · newline-delimited JSON
{"message":{"role":"assistant","content":"Be"},"done":false}
{"message":{"role":"assistant","content":"cause"},"done":false}
{"done":true,"done_reason":"stop"}

No event names, no sentinel: one object per line, ending with done.

05 · Serving

And the same four, outward

The dialects that write a request also read one, so a provider can answer in all four formats. Two formats claim /v1/models; the anthropic-version header decides which answers.

Ollama/api/chat /api/generate /api/embed /api/tags /api/show /api/version

Writing one more format adds one dialect, and the client and the gateway both have it: the direction you did not write is the one you already had.
