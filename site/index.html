同一段对话，四份请求体

系统提示「回答不超过一句话。」，用户问「为什么天空是蓝的？」，温度 0.2，上限 256，不开流式。四份都能直接发。

四家各自的规定

不看差异，接第二家最容易栽在这几条上。

  • Anthropic 的 max_tokens 是必填。 不传不会用默认值，直接 400；OpenAI 与 Ollama 都可以不给。
  • Gemini 的模型在路径里，参数在 generationConfig 里。 温度、上限、停止词都不在顶层，改名也改位置。
  • Ollama 的生成参数收在 options 里，流式默认开着。 要一次性拿完整回答，得显式写 "stream": false。
  • OpenAI 没有顶层 system 字段。 系统提示就是 messages 里的第一条，顺序本身带语义。
