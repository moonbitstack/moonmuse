02 · Four bodies

The same conversation, four complete requests

System prompt “Answer in one sentence.”, user asks “Why is the sky blue?”, temperature 0.2, cap 256, no streaming. Every one of the four can be sent as it stands.

03 · House rules

What breaks a second integration

Four things, in order of how often they do. None of them is a bug in either side — they are what the specification decides.

  • Anthropic requires max_tokens. Omit it and the request is rejected; there is no default. OpenAI and Ollama will fill one in.
  • Gemini puts the model in the path and the knobs under generationConfig. Temperature, output cap and stop sequences are renamed and relocated at the same time.
  • Ollama nests generation options under options, and streams by default. Ask for one response with "stream": false.
  • OpenAI has no top-level system field. The system prompt is the first message, so order carries meaning.

04 · Quick start

Ask a model, then change your mind

The provider is the only line that names a vendor. Swap the constructor and the request below is unchanged — the dialect decides where each field goes.

MoonBit 
moon add moonbitstack/moonmuse

let provider : &@moonmuse.Provider =
  @openai.Client::new(api_key="sk-…")

let request = @moonmuse.Request::new(
  "gpt-4o-mini",
  [@moonmuse.Message::user("Why is the sky blue?")],
  temperature=0.2,
  max_tokens=256,
)

let reply = provider.chat(request)
println(reply.text())
Four constructors
OpenAI@openai.Client::new(api_key=…, base=…)
Anthropic@anthropic.Client::new(api_key=…)
Gemini@gemini.Client::new(api_key=…)
Ollama@ollama.Client::new()
Bedrock@bedrock.Client::new(credential=…)
Scripted@fake.Fake::text("hello")

Every one of them implements the same Provider: chat, stream, embed, models. Layers and the scripted provider are providers too, which is why they compose in any order.

05 · Streaming and tools

One callback, four event shapes

Each vendor streams differently: a JSON chunk, seven named events, a candidate array, a line of NDJSON. All four arrive as the same deltas, and the returned value is the same reply chat gives.

Deltas 
let reply = provider.stream(request, delta => {
  match delta {
    @moonmuse.Delta::Text(chunk) => print(chunk)
    @moonmuse.Delta::CallStart(name~, ..) => println(name)
    @moonmuse.Delta::CallArgs(chunk~, ..) => print(chunk)
    @moonmuse.Delta::Done(_) => println("")
  }
})
Tools 
let tools = @toolbox.Toolbox::new()
tools.add(@moonmuse.Tool::new("add", "Add two integers"),
  args => {
    let a = @moonmuse.json_int(args, "a").unwrap_or(0)
    let b = @moonmuse.json_int(args, "b").unwrap_or(0)
    (a + b).to_string()
  })

let done = @toolbox.run(provider, request, tools, limit=10)

06 · Gateway

Turn one provider into all four APIs
